# Public controlled-initial ledger

`ledger.json` is a derived, metadata-free view of the controlled-initial
history run used for the original descriptive comparisons. It retains 384
logical cells, their completion status, round-level prices, rewards and
settlement welfare. Provider request IDs, fingerprints, token usage and raw
request/response payloads are intentionally excluded.

The source run contains 380 completed cells and four failed cells. The public
ledger is sufficient for descriptive state counts and transition summaries,
which are regenerated by `tools/controlled_initial_descriptives.py`; it is not
a replacement for the private raw request archive.

All counts in the derived summaries are descriptive. Repeated rounds are not
independent observations, and no new inferential endpoint is introduced.
